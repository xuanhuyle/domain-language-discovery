# Domain Language Discovery

Research program to find a narrow operational domain where domain-specific semantics or a language materially outperform existing AI, rules engines, and conventional software.

**Status:** Pre-discovery. Charter and protocol are drafts until explicitly approved by the repository owner.

No language, compiler, product, or industry is selected. Work proceeds through evidence-based research gates.

See the proposed founding documents in the research-setup pull request before starting the first deep research.
